전북대학교는 UI의 임의 수정·변형을 금지하고 사용 목적에 따라 허가를 요구한다. 이 저장소의 MIT 라이선스는 학교 명칭·로고에 대한 권리를 부여하지 않는다. 공개 배포 전에는 전북대학교의 서면 허가 및 최신 UI 지침을 별도로 확인해야 한다.
