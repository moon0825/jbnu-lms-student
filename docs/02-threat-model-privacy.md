# 위협 모델과 개인정보 처리 원칙

## 1. 보호 대상

| 자산 | 민감도 | 위치 |
|---|---|---|
| LMS 세션 쿠키(`MoodleSession*`), `sesskey`, (있다면) 웹서비스 토큰 | 매우 높음 — 탈취 시 학생 계정으로 LMS 전체 열람 가능 | Windows DPAPI 암호화 파일 / macOS 로그인 Keychain |
| 로그인·원문 보기용 전용 브라우저 프로필(LMS 쿠키) | 매우 높음 | `%LOCALAPPDATA%\jbnu-lms-mcp\browser-profile\`; 성공 후 LMS 쿠키만 유지하고 자격 증명·방문 기록·SSO 쿠키·사이트 저장소·캐시 제거 |
| 강좌·과제·공지 메타데이터 스냅샷 | 중간 — 개인 학습 정보 | `%LOCALAPPDATA%\jbnu-lms-mcp\state\snapshot.json` (평문 JSON, 제목·마감만) |
| 다운로드한 수업자료 | 중간~높음 — 저작물 | `~/Downloads/jbnu-lms/` |
| 사용자가 승인한 문제 신고·기능 제안 | 낮음~중간 — 사용자 작성 내용 | `%LOCALAPPDATA%\jbnu-lms-mcp\feedback\`; 선택 시 설정된 HTTPS 수집기 |
| 통합인증 아이디·비밀번호·패스키·OTP | 최고 | **이 프로그램은 취급하지 않음** |

## 2. 신뢰 경계

```
사용자 ──(브라우저, 직접 인증)──▶ sso.jbnu.ac.kr ──▶ lms.jbnu.ac.kr
   │                                                   ▲
   │ MCP 클라이언트(Claude Desktop/Codex) ── STDIO ──▶ jbnu-lms-mcp ──HTTP(쿠키)──┘
   │                                                   │
   └── 로컬 보안 저장소(DPAPI/Keychain), 정리된 LMS 전용 프로필, 스냅샷 ◀┘
```

- MCP 서버는 로컬 STDIO 로만 동작하며 네트워크 포트를 열지 않는다.
- LMS 호스트(`lms.jbnu.ac.kr`) 외의 어떤 호스트에도 쿠키·토큰을 보내지 않는다(`http/client.ts` 의 호스트 고정). 외부로의 리다이렉트는 따라가지 않는다.
- SSO 호스트에는 자동화를 붙이지 않는다. 세션 검증용 headless 브라우저는 LMS 호스트 외 요청을 전부 차단한다.
- 피드백 수집기는 LMS HTTP 클라이언트와 분리되어 쿠키·`sesskey`·Moodle 토큰에 접근하지 않는다. 사용자 승인 시에만 최소화된 JSON을 보내며 외부 HTTP와 리다이렉트를 거부한다.

## 4. 개인정보 처리 원칙

1. **최소 수집**: 표시 이름과 사용자 ID 외의 프로필 정보는 저장하지 않는다. 학번은 저장·로그하지 않는다.
2. **로컬 우선**: LMS 학업 데이터와 인증정보는 사용자 PC와 LMS 사이에서만 처리한다. 피드백은 사용자가 내용·수집 위치를 확인하고 승인한 경우에만 별도 수집기로 전송한다.
3. **삭제권**: `disconnect_lms`로 세션·프로필·스냅샷을 삭제하고 `discard_local_feedback`으로 로컬 피드백 사본을 삭제할 수 있다. 이미 원격 전송된 사본은 수집기 정책에 따라 별도 삭제 요청이 필요하다.
4. **투명성**: 모든 응답에 데이터 출처(공식 API/AJAX/화면 해석/AI 추정)와 원문 URL 을 표시한다.
5. **저작물 존중**: 수업자료는 사용자가 명시적으로 요청할 때만 다운로드하며 자동 수집하지 않는다. 자료의 재배포는 학교 규정을 따른다.
6. **테스트 데이터**: 기본 테스트는 익명화된 fixture 와 로컬 mock 서버만 사용한다. 명시적으로 켜는 실환경 검증은 항목 개수와 성공 여부만 출력하며 실제 본문·이름은 저장소에 넣지 않는다.
7. **피드백 투명성**: 자동 오류 보고·백그라운드 텔레메트리는 사용하지 않는다. 접수 도구는 수집 방식, 접수 번호, 전송 여부를 즉시 반환한다.
8. **판단과 실행 분리**: 학생 확인함·제출 확인·캘린더 후보는 로컬 판단 결과이며 LMS 제출, 출석, 캘린더 쓰기를 실행하지 않는다.
8. **원문 열기 격리**: 일반 채팅 브라우저에 쿠키를 주입하지 않는다. 별도 전용 프로필로만 열고 쿠키·토큰을 URL이나 명령행에 넣지 않는다.

## 5. 사용자가 알아야 할 사항

- 이 도구를 설치한 PC 에 로그인할 수 있는 사람은 저장된 LMS 세션을 쓸 수 있다. 공용 PC 에서는 사용을 마친 뒤 반드시 `disconnect_lms` 를 실행하라.
- LMS 세션은 보통 8시간 유휴 후 만료된다. keep-alive 를 켜 두면 MCP 서버가 살아 있는 동안 계속 연장된다.
- 통합인증 화면에 나타나는 어떤 정보도 이 도구는 읽지 않는다. 비밀번호·인증 코드를 채팅에 입력하지 마라.
