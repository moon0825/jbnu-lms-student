플러그인 설명과 README 첫 화면에 전북대학교가 운영하거나 보증하는 공식 서비스가 아니라는 문구를 표시한다. 로그인 화면, 학교 홈페이지, LMS 화면을 복제하거나 공식 고객지원 창구인 것처럼 표현하지 않는다.

## 자산 출처와 사용 조건

로고는 전북대학교 공식 UI 페이지의 `UI 인쇄용, 웹용` ZIP에서 받은 원본을 변형하지 않고 사용한다.

- UI 안내: <https://www.jbnu.ac.kr/web/intro/university/sub05.do>
- 공식 ZIP: <https://www.jbnu.ac.kr/file/sub/ui.zip>
- 로컬 원본·해시 기록: [`assets/README.md`](../assets/README.md)

공식 안내는 UI의 임의 수정·변형을 금지하고 전북대학교의 허락 없는 복제·사용을 제한한다. 따라서 개인 개발·교내 검토를 넘어 공개 배포하려면 학교의 서면 허가와 최신 사용 지침을 먼저 확인해야 한다. 프로젝트의 MIT 라이선스는 학교 로고와 명칭에 적용되지 않는다.
