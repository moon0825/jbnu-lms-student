# 실제 JBNU LMS 검증 기록

실제 학생 계정의 제목·이름·본문·쿠키·토큰은 이 문서와 테스트 출력에 기록하지 않는다. 아래에는 개수와 성공 여부만 남긴다.

## 2026-09-04 · 0.2.0

환경: Windows 11, Node.js 22.11, Google Chrome, JBNU LMS 3.0, `plain` 로그인.

| 검증 항목 | 결과 |
|---|---|
| LMS `/my/` 세션 검증 | 통과 |
| 수강 강좌 목록 | 4개 조회 |
| 현재 강좌 공지 목록 | 2건 조회 |
| `ubboard` 공지 본문 | 제목·작성일·조회수·본문 파싱 통과 |
| 강좌 섹션 | 16개 조회 |
| 현재 노출 과제·마감·수업자료 | 0건(현 시점 강좌 화면에 해당 모듈 없음) |
| 실환경 스모크 | 3/3 통과 |
| 설치본 MCP 프로토콜 | 도구 15개 로드, 인증·공지·일일 브리핑·주간 계획·자료 조회 호출 성공 |

발견하고 수정한 계약 차이:

- 공지 목록은 예전 HTML `table`뿐 아니라 현재 Coursemos의 `.grid-table > .grid-row` 구조를 사용한다.
- 공지 본문은 `.ubboard_view` 대신 `.ubboard .article-header`, `.article-title`, `.article-content` 구조를 사용한다.
- 패스키 인증 뒤 학교 SSO가 포털로 복귀할 수 있어, 동일 전용 프로필로 LMS `/my/`를 다시 여는 복구가 필요하다.

실행 명령:

```powershell
$env:JBNU_LIVE='1'
npm run test:live
```

이 검증은 조회 전용이며 LMS 상태를 변경하지 않는다.
